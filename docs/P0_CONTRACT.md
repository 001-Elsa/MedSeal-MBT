# P0 行为与验证契约

## 输入发现

扫描所有普通文件，最多 20,000 个条目；每个文件读取最多 132 字节探测。
带 DICM 标记的 Part 10 不受扩展名限制；扩展名为 .dcm 但缺少标记的文件
仍进入解析并明确拒绝。其他普通文件计入 excluded，不静默计为已处理。
拒绝符号链接、特殊文件、深度超过 16 和候选超过 10,000。

plan、execute 和发布前复核候选与排除文件集合。排除原因仅输出分类与计数，
公开结果不出现原始文件名。此阶段继续要求受控稳定输入，不承诺敌对管理员快照安全。

## 状态

结果状态分别记录转换、完整性/结构验证、风险和交付许可。
当前 metadata-subset 转换成功不获得外部交付许可；像素未经检查。
basic 单文件入口维持兼容能力，并明确其保证弱于集合处理。

## 故障注入

按作业实例注入观察/存储操作，不使用全局状态或隐藏环境开关。
观察点：stage-created、before-object、object-verified、before-manifest、
before-publication。存储点：create、after-partial-write、before-sync、publish。
注入异常走实际清理/失败路径；真实 OS 磁盘满与模拟写入失败分别记录。

## 最小门槛

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| P0-01 | 无扩展名影像与非影像混合 | 候选/排除/总数守恒 |
| P0-02 | 执行中修改尚未处理对象 | 失败，无最终目录 |
| P0-03 | 第 N 次 create / 部分写入 / sync / publish 失败 | 无完成目录；暂存清理 |
| P0-04 | 同目标竞争、父目录别名、硬链接 | 不覆盖、不绕过嵌套检查、明确拒绝/报告 |
| P0-05 | 读取、扫描和解析资源边界 | 边界内允许，超限明确拒绝 |
| P0-06 | 硬终止 | 不误发布；暂存保持私有并有清理指南 |
| P0-07 | 大像素/RSS/磁盘测量 | 载荷不变；报告机器与负载；不推算临床吞吐 |

记录必须区分真实系统故障、测试注入与尚未认证条件。
