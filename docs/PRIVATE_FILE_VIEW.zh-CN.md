# 本地真实文件私有视图设计（V5）

本阶段交付设计与验收约束，尚未开放真实文件导入。已运行的页面只使用固定合成样例，不能将设计写成现有功能。

## 用户任务和流程

用户先选择“本机私有检查”，页面明确说明仅本机内存处理、不上传、不授予发布；用户自行选取普通DICOM文件。开始前显示对象数和总大小预算，不在默认页面显示原值。先检查传输语法/字符集/字段/引用，随后仅展示公开结构与受限错误。需要查看原值时独立显式打开私有区域，关闭/重置立即清除相关DOM与引用；文件名本身也是私有数据。

真实文件模式与合成教学模式使用独立状态，切换时清空输入、结果、比较和导出。不能沿用教学固定seed和1天偏移处理真实作业。首版只检查，不在浏览器生成真实去标识影像；真实转换与签名交付仍使用本机固定运行包及原审核链。

## 内存、数据和导出边界

先检查File.size再读取；至多16对象、合计16MiB、每对象8MiB，主线程与Worker分离，取消时终止Worker并释放引用；解析后仍遵循MoonBit限制。禁止localStorage、IndexedDB、Service Worker、遥测、错误内容上报和URL查询携带文件信息。公开导出仅经过现有解释白名单，原值/文件名/UID/日期/策略值不得混入；私有导出若未来需要必须另设按钮与明确提示，不能复用公开报告按钮。

数据只在内存是设计边界，不保证操作系统交换区、崩溃转储、浏览器扩展或恶意本机管理员不会访问。该限制应简短说明，不能以“完全不可恢复”描述垃圾回收或DOM清除。

## 开放真实导入前必须验证

1. 先有清楚授权和去患者化测试输入，不用患者文件截图。
2. File.size超限在arrayBuffer前拒绝；取消、重复运行、失败和模式切换清空旧结果。
3. Worker终止与内存上限实测；不复制多份hex放大内存，使用有界ArrayBuffer传输。
4. 浏览器实际执行CSP，禁止网络、未授权脚本、存储；注入策略/文件名/原值金丝雀不能进入公开JSON、DOM公共区或下载名称。
5. 键盘/焦点/读屏标签、390px及桌面、真实下载和错误恢复独立验收。
6. 完成对应威胁模型、支持矩阵和源码发行回读，验证前不在正式页面开放导入。

这些是后续新增功能的放行条件，不影响已完成的合成实验室真实浏览器验收。
