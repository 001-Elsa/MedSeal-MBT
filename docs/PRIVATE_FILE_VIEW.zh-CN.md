# 本机私有文件只读检查

当前 0.5.0 源码继续保留此只读入口及其独立浏览器预算；它不会自动获得新 Native 查询/导出/转换命令。下文 0.4.1 浏览器验收为历史已测范围，本轮未将其写成重新执行。

0.4.1 已开放浏览器本机文件选择、只读验证、匿名结构、显式私有文本查看、取消/清除及匿名摘要下载。使用 `python3.12 tools/build_community_lab.py` 生成页面，打开 `tmp/community-lab/index.html`，选择“本机私有文件 · 只读检查”。

## 可直接操作的流程

1. 选择本人有权处理的 DICOM 文件；文件名仅在浏览器原生文件选择控件中出现，不写入结果。
2. 点击“开始只读检查”。先核对 1–16 个非空对象、每对象 8 MiB、合计 16 MiB 的预算，再读取文件。
3. ArrayBuffer 转移给独立 Worker，主线程的缓冲区被分离；Worker 调用 MoonBit `inspect_private`，复用公开验证与封闭集合关系检查。没有调用教学转换、seed 或日期平移。
4. 默认只显示匿名对象编号、Tag/Sequence 路径、VR 和对象/引用数量；点击“显示所选对象的私有文本原值”才显示原文。最多 128 项、每项 160 UTF-16 单位，不显示像素或二进制内容。
5. 匿名摘要只含 schema、scope、status、objects、references、release_authorized:false。文件名、路径、患者原值、UID、日期和私有文本结果不进入下载；下载名固定。
6. 点击取消、清除、关闭原值或切换模式，终止 Worker 并清空输入、原值 DOM、公开结果和导出状态。15 秒超时同样终止，不保留部分成功。不能通过关闭原值继续沿用旧私有输入。

只读通过表示受支持原始对象/当前封闭集合通过检查，**不表示已脱敏**。真实转换、复核、签名交付使用现有本地宿主流程。输入必须满足当前支持矩阵；压缩传输语法或未支持的对象继续拒绝。

## 处理与安全边界

页面不使用网络、遥测、localStorage、sessionStorage、IndexedDB 或 Service Worker；CSP 阻止联网和未授权脚本，`worker-src blob:` 只用于打包在页面中的固定 Worker。文件内容使用 `textContent` 显示，不解释为 HTML。页面内没有私有导出功能。

Worker 复核数量/字节预算，MoonBit 再独立检查相同预算，随后适用解析深度/元素等限制。输入字节限额不是浏览器进程总内存限额；解析结构、运行时与浏览器自身会额外占用内存。取消不会承诺物理擦除已释放内存，也不控制浏览器扩展、系统交换区或崩溃转储。

## 实际验收

```sh
node tools/verify_private_browser.mjs
```

使用隔离 Chromium 和固定非患者合成文件。实际验证原生文件选择、键盘按钮触发、Worker 二进制转移、公开摘要精确字段、显式原值显示、恶意文本安全显示、超预算读取前拒绝、断引用/重复/损坏拒绝、取消/超时/切换清除、390px布局、真实下载、CSP和无存储写入。记录 `tmp/community-lab/private-acceptance.json`。

测试同时记录隔离浏览器后代进程的 RSS 快照，明确是观察值，不冒充峰值或 Worker 专用堆上限。四后端测试另覆盖核心预算、错误不回显及私有原值索引。没有使用患者数据截图，也不把本机工程测试当作机构现场验收。
