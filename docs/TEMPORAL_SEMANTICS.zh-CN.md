# 日期时间语义契约（W2）

MedSeal 把 DICOM 的 DA、DT、TM 当作三种不同的值域处理。解析器记录原始精度、小数秒位数、显式时区和闰秒标志；缺失值、空值和精度不足不会被补全成更精确的时间。

默认 `metadata-safe-v1` 保持既有安全策略：日期类标识按现有规则清空或按固定日期策略处理，TM 没有日期上下文时不做整日平移。启用 `retain-dt-precision-v1` 后，只有完整日期部分的 DT 才按患者一致的日期偏移移动；时分秒、小数秒和显式时区后缀原样保留。只有年月等低精度 DT 会被清空，不会假造日、秒或时区。单独的 TM 不参与日期平移。

显式偏移不被偷偷换算成 UTC；`-0000`、非法分钟、非法日期和超出年份范围的值被拒绝。合法闰秒可以被解析，但在发生非零日偏移且无法证明移动后的闰秒语义时，作业以 `temporal-precision` 的未知条件阻断。该契约只覆盖已声明的属性值语法，不等同于完整 IOD 或临床时间语义认证。

规则来源与边界案例在 `resources/rules/contracts-v1.json`、`src/date/temporal_test.mbt` 和 W2 增量验收中固定；公开解释只输出规则、来源和动作，不输出原始患者时间值。
