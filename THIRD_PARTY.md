# Third-party and data provenance

MedSeal-MBT is an original MoonBit implementation. It is not a port of another
DICOM library and contains no copied DICOM parser or de-identification code.

## MoonBit dependencies

| Dependency | Version | Purpose | Repository | License |
| --- | --- | --- | --- | --- |
| `moonbitlang/async` | 0.20.4 | Atomic asynchronous file rename | https://github.com/moonbitlang/async | Apache-2.0 |
| `moonbitlang/x` | 0.4.48 | Filesystem, path, UTF-8, and JSON support | https://github.com/moonbitlang/x | Apache-2.0 |

Both licenses are compatible with this project's Apache-2.0 license. Exact
versions are declared in `moon.mod` and resolved by `moon update`.

## Test and sample data

Every `.dcm` file under `samples/` is generated by
`tools/generate_samples/main.mbt`. The fixtures contain invented names,
identifiers, UIDs, institution text, and tiny synthetic Pixel Data byte arrays.
They do not originate from a patient, hospital, scanner, public clinical
dataset, or third-party DICOM project. Regeneration instructions and the role
of every fixture are documented in `samples/README.md`.

## Generated interfaces and AI assistance

`pkg.generated.mbti` files are generated by the MoonBit toolchain using
`moon info` and are committed so public interfaces can be reviewed. AI tools
assisted implementation, review, tests, and documentation; the repository
owner remains responsible for behavior, scope, licensing, and submitted data.
